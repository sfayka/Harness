# Archived macOS App Materials

These files preserve the removed native macOS app direction for historical reference only.

Harness now supports CLI/runtime, backend API, and web dashboard operator surfaces. Do not use the archived Swift app, DMG packaging, notarization, Launch at Login, menu-bar, onboarding, or notification notes as active implementation guidance unless the product decision is explicitly reopened.

Archived groups:

- `architecture/`: historical Swift shell and packaging design notes.
- `release/`: historical release-readiness and first-run validation notes.
- `specs/`: historical local-app product spec.
